Proposed auto-update for skills

  • When: in the same logon task, at most once a week (skills move slower than benchmarks, and the check costs more).
  • Script, no model: for each baseline entry, compare the pinned commit/hash with upstream (gh api, npx skills check), plugin versions, and skills.sh audit status.
  • Model, web tools only (no edit, no shell): Sonnet at high. This is judgement, not number-reading, and the table puts Sonnet high on "implementation from a clear brief". It reads what changed upstream and looks on skills.sh, find-skills, GitHub and community sources for better alternatives or new risks. It returns structured findings (update / replace / add / remove / risk), each with evidence links.
  • Nothing is applied automatically. If there are findings: a sticky toast "skill findings: N proposals", with Open report (this format) and Review with Claude. The second opens Claude Code in agent-config with the report loaded; you say yes, no or something else per item, and that session applies, installs and commits locally.
  • No findings: silent, like the benchmark check.
